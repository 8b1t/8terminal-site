1.0.5

not released yet · Mac · iPhone and iPad

Mac

8Terminal Pro is now $5.99 (€5.99, £5.99), once, for every Mac, iPhone and iPad on your Apple Account and your Family Sharing group. No subscription.

New in this version:

  • Split panes: Cmd+D and Shift+Cmd+D, up to four per tab
  • Sign in through your SSH agent or a Secure Enclave key with Touch ID
  • OpenSSH certificates, including a clear message when one has expired
  • Agent forwarding that asks before every signature
  • Chains of up to four jump hosts, and environment variables per host
  • Two-factor keyboard-interactive sign-in; RSA keys in OpenSSH and PuTTY files
  • Generate a key and install it on a host from the app
  • Automatic reconnect and a tmux / zellij session picker
  • A notification when a coding agent is waiting for you
  • Paste a screenshot or a Finder file into the terminal
  • SFTP: folders, drag from Finder, permissions, keep both, and resume after a dropped connection
  • Twelve themes, iTerm and Ghostty theme import, a theme per host, Nerd Font symbols
  • Export and import hosts as JSON without secrets
  • Find in the terminal with Cmd+F
  • Cmd+T, Cmd+W and Cmd+1–9 for tabs; rename a tab or drag it to reorder
  • The command palette connects to hosts and runs snippets
  • Cmd-click opens https links, after you confirm
  • Option as Meta, and clipboard copy from tmux and Neovim (asks once per session)
  • Import and export OpenSSH known_hosts
  • IBM Plex Mono, and complete light and Solarized colors
  • A Drive backup made on iPhone or iPad now restores on the Mac

iPhone and iPad

8Terminal Pro is now $5.99 (€5.99, £5.99), once, for every Mac, iPhone and iPad on your Apple Account and your Family Sharing group. No subscription.

New in this version:

  • Home Screen widget with your recent hosts, and Shortcuts to connect, run a snippet or start a tunnel
  • Live Activity buttons: Return, Ctrl-C and Reconnect, plus a note when a coding agent is waiting
  • iPad hardware keyboard: Esc, Tab, Ctrl keys, Cmd+T, Cmd+W and Cmd+1–9
  • Two-factor keyboard-interactive sign-in; RSA keys in OpenSSH and PuTTY files
  • Generate a key and install it on a host from the app
  • OpenSSH certificates, and chains of up to four jump hosts
  • A Secure Enclave key with Face ID, and agent forwarding that asks before every signature
  • Find in the terminal, https links, and a key row you can rearrange with your own snippets
  • Dictation now arrives in full
  • Automatic reconnect and a tmux / zellij session picker
  • Paste a screenshot into the terminal, with its location data removed
  • SFTP: folders, permissions, Quick Look, keep both, and resume after a dropped connection
  • Twelve themes, a theme per host, Nerd Font symbols
  • Export and import hosts as JSON without secrets
  • More keys on the key row: Shift-Tab, Shift-Return, Home, End, Page Up/Down, F1–F12 and the symbols coding agents ask for
  • A visible flash when a program rings the bell
  • A Drive backup made on the Mac now restores here

1.0.4

September 2026 · Mac · iPhone and iPad

Mac

Fixed local folder selection for SFTP in the Mac App Store sandbox. You can now choose a local folder and securely browse, upload, and download files.

iPhone and iPad

Saved passwords now complete reliably after Face ID or passcode confirmation in SSH terminal prompts. This update also improves protected terminal input handling on iPhone and iPad.

1.0.3

September 2026 · Mac · iPhone and iPad

Securely use saved passwords for sudo, su, and other terminal prompts with explicit credential selection and Face ID, Touch ID, or master-password confirmation. This release also strengthens terminal input ordering and lifecycle safety across Mac, iPhone, and iPad.

1.0.2

August 2026 · Mac

Vault sync now pauses when 8Terminal Pro expires instead of continuing, and says so. Your local vault, your hosts and your keys are untouched and stay fully usable; renewing resumes the same sync without pairing your devices again.

The 8Terminal Pro card now shows the renewal terms for each plan and links to the Terms of Use and the privacy policy.

Fixes throughout the file browser: transfers that stop because the destination already holds the file now ask which one you want instead of reporting a failure, and the workspace no longer squeezes itself on narrow windows.
